# VOTE 🗳️ - Decentralized Blockchain Voting System

A secure, transparent, and tamper-proof voting platform built on **Ethereum smart contracts** using **Hardhat**.  
The frontend is powered by **React** with seamless **Metamask integration** for voters.  

---

## 🚀 Features

- **Smart Contract Voting**
  - Written in Solidity
  - Deployed with Hardhat
  - Ensures transparency and immutability

- **Frontend**
  - React + Tailwind CSS
  - User-friendly voting UI
  - Wallet connection with MetaMask

- **Backend**
  - Hardhat scripts for deployment & testing
  - TypeChain for type-safe contract interactions

- **Security**
  - Environment variables managed with `.env`
  - Private keys & API keys excluded via `.gitignore`

---

## 🛠️ Tech Stack

- **Blockchain:** Ethereum, Solidity, Hardhat  
- **Frontend:** React.js, Tailwind CSS, ethers.js  
- **Tools & Libs:** TypeChain, MetaMask, dotenv  
- **Testing:** Hardhat Chai/Mocha, solidity-coverage
